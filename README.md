## نظرة عامة

منصة **العالمي (Alalme)** هي منظومة تجارة إلكترونية متكاملة ومتعددة المتاجر لقطاع قطع غيار السيارات. تجمع المنصة بين العملاء، أصحاب المتاجر، ومسؤولي الإدارة في بيئة موحدة تعتمد على محرك هندسي متطور لمطابقة القطع مع مواصفات المركبات (Vehicle Fitment Engine) استناداً إلى بيانات الإدارة الوطنية لسلامة المرور على الطرق السريعة (NHTSA) وفك شفرة رقم الهيكل (VIN Decoder).

تتكون المنصة من واجهة ويب متجاوبة فائقة السرعة مبنية بـ React 19، وتطبيق جوال أصيل لنظامي iOS و Android مبني بـ React Native Expo 57، وتعتمد في معالجة الأعمال على خادم خلفي متين بـ Laravel 11 وقاعدة بيانات PostgreSQL 16، مع نظام أمان متقدم للمصادقة السحابية (Clerk) ونظام صارم لإدارة الصلاحيات (RBAC).

## أهم الميزات

### 🚗 العميل (Customer)
- **المرآب الافتراضي (My Garage):** حفظ وإدارة مركبات العميل مع رقم الهيكل (VIN) ورقم اللوحة، وتحديد مركبة افتراضية.
- **التحقق اللحظي من التوافق:** شارة ذكية في صفحة المنتج تفيد بالتوافق الهندسي مع سيارة العميل أو عدمه.
- **البحث المتطور والتصنيف:** بحث برقم القطعة (SKU / Part Number / OEM)، مع فلاتر الماركات والمدن والأسعار.
- **سلة الشراء متعددة المتاجر:** تجميع قطع من متاجر وفروع مختلفة في طلب واحد مع تجزئة الشحنات آلياً.
- **متابعة الطلبات والشحنات:** تتبع مسار كل شحنة فرعية والتواصل مع المتاجر وتقييم المنتجات.

### 🏬 مالك المتجر (Shop Owner)
- **إدارة الفروع المتعددة:** إضافة وتعيين فروع المتجر الجغرافية وربطها بالمدن وإحداثيات الخريطة.
- **إدارة طاقم العمل:** دعوة الموظفين وتعيينهم للفروع وتحديد صلاحياتهم الوظيفية.
- **كتالوج المنتجات والمخزون:** إضافة القطع، رفع الصور، ربط توافق السيارات، والتحكم اللحظي بمستويات المخزون وحركاته.
- **معالجة وتنفيذ الطلبات:** استلام وتأكيد طلبات المتجر، تحديث حالات التجهيز، وإصدار الفواتير والتقارير المالية.

### 👷 موظف المتجر (Shop Employee)
- **العمل بنطاق الفرع:** حصر صلاحيات الموظف بالفرع الجغرافي المعين له دون الوصول للبيانات الحساسة للمتجر.
- **تجهيز الطلبات:** استلام إشعارات الطلبات وتحديث حالات الفحص والتغليف والشحن.
- **تسوية المخزون السريعة:** إدخال وتعديل كميات الرفوف وإثبات حركات الجرد الفعلي.

### 🛡️ إدارة المنصة (Admin & Super Admin)
- **مركز القيادة (Dashboard):** مؤشرات حية لحجم المبيعات الكلي، عدد الطلبات، والمستخدمين النشطين.
- **طابور اعتماد المتاجر:** مراجعة وثائق المتاجر وتراخيصها والموافقة عليها أو رفضها أو تجميدها.
- **محرك الصلاحيات (RBAC):** استنساخ وتعديل الأدوار، ومصفوفة الصلاحيات، واستثناءات الصلاحيات الفردية.
- **الرقابة والتدقيق الأمني:** مراقبة شاملة للمخزون، إدارة العمولات، وسجل تدقيق إداري غير قابل للتعديل (Audit Logs).

## الأدوار والصلاحيات

تعتمد المنصة محرك صلاحيات متعدد الطبقات يحسب الصلاحيات الفعلية لكل مستخدم وفق المعادلة الرياضية:

```text
Effective Permissions = (Role Base Permissions + User Granted) - User Denied
```

- **الأدوار النظامية:** `SUPER_ADMIN` (كامل الصلاحيات دون استثناء)، `ADMIN` (إدارة المنصة)، `SHOP_OWNER` (إدارة المتجر وفروعه)، `SHOP_EMPLOYEE` (تشغيل الفرع والمخزون)، و `CUSTOMER` (التسوق والمرآب).
- **نطاقات الصلاحيات (Scopes):** `PLATFORM`, `SHOP`, `BRANCH`, `OWN`, و `ASSIGNED`.
- يدعم النظام استنساخ الأدوار المخصصة، ومصفوفة الصلاحيات المرئية، واستثناءات الصلاحيات الفردية.

> التوثيق الكامل متوفر في [دليل الصلاحيات والأدوار](docs/rbac.md).

## قاعدة البيانات

تتألف قاعدة البيانات في **PostgreSQL 16** من **44 جدولاً علائقياً** موثقاً من ملفات الـ Migrations، مقسمة إلى 13 قطاعاً وظيفياً:

1. **المستخدمون والمصادقة (3 جداول):** الحسابات، العضويات، وعناوين التوصيل.
2. **نظام الصلاحيات (4 جداول):** الأدوار، الصلاحيات، الربط المحوري، واستثناءات المستخدمين.
3. **الجغرافيا (جدولان):** الدول والمدن المدعومة.
4. **المركبات والتوافق (7 جداول):** الماركات، الموديلات، السنوات، المواصفات الفنية، ومركبات المرآب.
5. **المتاجر والشركاء (4 جداول):** المتاجر، الفروع الجغرافية، طاقم العمل، ونسب العمولات.
6. **كتالوج المنتجات (5 جداول):** التصنيفات، المصنعين، قطع الغيار، الصور، وجدول التوافق الفني.
7. **المخزون والمستودعات (جدولان):** كميات الفروع وسجل حركات الجرد التفصيلي.
8. **سلة التسوق (جدولان):** السلات النشطة وعناصر السلة.
9. **الطلبات والتجزئة (4 جداول):** رأس الطلب الموحد، مجموعات المتاجر الفرعية، الأصناف، وسجل الحالات.
10. **الخدمات اللوجستية (جدول واحد):** الشحنات وبوليصات التتبع.
11. **المدفوعات (جدولان):** سجل الدفع والعمليات المشفرة مع بوابات الدفع.
12. **التسويق والتفاعل (4 جداول):** التقييمات، الشكاوى، قائمة الرغبات، والكوبونات.
13. **الإعلانات والتدقيق (4 جداول):** البانرات، الإشعارات، إعدادات المنصة، وسجل التدقيق الأمني.

> استعراض الحقول والعلاقات متاح في [دليل قاعدة البيانات](docs/database.md).

## واجهة برمجة التطبيقات (API)

توفر المنصة واجهة RESTful API كاملة ومحمية بـ JWT:

- **المسارات العامة (Public):** كتالوج السيارات، الماركات، فك شفرة VIN عبر NHTSA، شجرة التصنيفات، البحث، والمتاجر.
- **مسارات المصادقة (Auth):** استرجاع الملف الشخصي وتحديث بيانات المستخدم وتسجيل المتاجر.
- **مسارات العميل (Customer):** إدارة المرآب الشخصي، سلة التسوق، إنشاء الطلبات وتتبعها، التقييمات، وقائمة الرغبات.
- **مسارات إدارة المتجر (Shop):** إدارة الفروع والموظفين، كتالوج القطع، جرد المخزون، ومعالجة الطلبات.
- **مسارات مركز التحكم الإداري (Admin):** لوحة القيادة، اعتماد المتاجر، إدارة المستخدمين، مصفوفة الصلاحيات، والتقارير وسجل التدقيق.

> جداول الـ Endpoints التفصيلية متوفرة في [دليل الـ API](docs/api.md).

## التشغيل السريع

### المتطلبات الأساسية
- Node.js 20+ | PHP 8.2+ | Composer 2.x | PostgreSQL 16+

### 1. تشغيل الواجهة الخلفية (Backend)
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve --port=8000
```

### 2. تشغيل الواجهة الأمامية (Frontend)
```bash
# من المجلد الرئيسي للمشروع
npm install
cp .env.example .env
npm run dev
# التطبيق يعمل على المنفذ 3000 مع Proxy تلقائي لـ API
```

### 3. تشغيل تطبيق الجوال (Mobile)
```bash
cd mobile
npm install
cp .env.example .env
npx expo start
```

> تعليمات التطوير المتقدمة متوفرة في [دليل التطوير](docs/development.md).
